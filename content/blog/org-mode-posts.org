#+TITLE: Writing posts in Org mode
#+DATE: 2026-10-23
#+DESCRIPTION: Org files in content/ are converted to Zola posts automatically.
#+FILETAGS: :tutorial:org:

* How it works

Any =.org= file inside =content/= is converted to Markdown by ~pandoc~
(through the =org2zola= script) before Zola builds the site. The generated
=.md= file sits next to it. Edit the =.org= file, never the generated one.

* Header keys

| Key            | Becomes                          |
|----------------+----------------------------------|
| =#+TITLE:=       | post title                       |
| =#+DATE:=        | post date                        |
| =#+DESCRIPTION:= | description                      |
| =#+FILETAGS:=    | tags, like =:nix:linux:=         |
| =#+DRAFT:=       | set to =true= to hide the post   |

* Formatting

You get *bold*, /italic/, ~inline code~, and [[https://www.getzola.org][links]].

** Lists

1. Numbered lists
2. keep their order
   - and can nest

** Code blocks

#+begin_src nix
{ pkgs, ... }: {
  environment.systemPackages = [ pkgs.zola pkgs.pandoc ];
}
#+end_src

#+begin_src python
def greet(name):
    return f"hello, {name}!"
#+end_src

* Images

Put the image next to the post and link it:

: [[file:photo.png]]

Org links to files become normal Markdown images. For a post with images,
use a folder: =content/blog/my-post/index.org= plus the image files.
